# Product

## Platform
Web application also displayed inside an Android WebView.

## Stack
Existing FastAPI server, plain HTML/CSS/JavaScript, WebRTC, Google Gemini Live.

## User and task
Russian-speaking participants join the same room, place or receive an internet voice call, and inspect speech and fraud-risk analysis on the receiver side. This description is inferred from the repository and the requested redesign; no new product claims are introduced.

## Constraints
One room, two roles, foreground only. Preserve explicit consent, origin checks, one-use audio tickets, truthful unavailable/incomplete analysis states and call lifecycle. Remove the shared access-secret mechanism as explicitly requested. Do not imply low risk guarantees safety. Keep Google API credentials on the server.

## Design brief
User delegated interface design. Improve the shared calling page for desktop and Android-sized viewports. Use existing Russian product content and preserve all controls.
